# Rigorous Brainstorm

Use this only when the user requests alternatives or the approved problem has at least two consequential directions. Interface-shape exploration belongs to `design-an-interface`.

## Diverge

Run one parallel round with two or three fresh-context agents. Give each the same goal and constraints but a different role, objective, or risk preference. Require distinct proposals, tradeoffs, assumptions, and failure conditions.

## Converge

The parent rejects proposals that violate the goal or evidence, then recommends one candidate or a justified synthesis.

Run one focused adversarial round against that candidate. Fix local weaknesses once. If a fundamental constraint remains unresolved, report it or return to `grill-me`; do not launch unbounded additional rounds.

Return only viable options, the comparison, the recommendation, and decisions still owned by the user.
